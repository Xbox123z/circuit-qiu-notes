# 第三章 电阻电路的一般分析　复习笔记

（编写：Arena · claude-sonnet-5-5-high）

##

核心思想：不改变电路结构，以 KCL、KVL 和元件 VCR 为依据，选取一组独立变量，列写独立方程，系统求解。

1. 电路的图：节点、支路、回路、树、基本回路
2. 独立方程数：KCL 为 $n-1$ 个，KVL 为 $b-n+1$ 个
3. 方程法（按未知量划分）：
- 支路电流法（未知量 $b$ 个）
- 网孔电流法（未知量 $b-n+1$ 个，仅限平面电路）
- 回路电流法（未知量 $b-n+1$ 个，适用于任意电路）
- 节点电压法（未知量 $n-1$ 个）
4. 特殊处理：无伴电流源、无伴电压源、受控源、弥尔曼定理

##

- 图 $G$：节点与支路的集合。每条支路用线段表示，不管支路上是什么元件。给支路标方向后得到有向图。
- 连通图：任意两节点之间至少存在一条路径。
- 回路：从某节点出发，经过不重复的支路和节点回到出发点的闭合路径。
- 平面图：可以画在平面上且支路不交叉的图。网孔是内部不含其他支路的回路。
- 树 $T$：满足三个条件的子图：①连通；②包含全部节点；③不含回路。
- 树支数 $= n-1$，连支数 $= b-n+1$。
- 同一个图可以有多棵树。
- 基本回路（单连支回路）：只含一条连支、其余均为树支的回路。基本回路数 $=$ 连支数 $= b-n+1$，它们彼此独立。
- 独立回路：每个回路都含有其他回路没有的新支路。对平面电路，$b-n+1$ 个网孔就是一组独立回路。
- 自阻 $R_{kk}$：第 $k$ 个网孔（回路）内所有电阻之和，恒为正。
- 互阻 $R_{jk}$：网孔（回路）$j$、$k$ 公共支路上的电阻之和，符号可正可负。
- 自导 $G_{kk}$：与节点 $k$ 相连的所有支路电导之和，恒为正。
- 互导 $G_{jk}$：节点 $j$、$k$ 之间所有直接相连支路的电导之和，取负号。
- 无伴电源：没有电阻与之串联（电流源则是没有电阻与之并联）的理想电压源（理想电流源）。

##

1. 独立方程数
独立 KCL 方程数 $= n-1$，独立 KVL 方程数 $= b-n+1$

$$b = (n-1) + (b-n+1)$$

支路电流法恰好列出 $b$ 个方程，与支路数相等。

2. 网孔电流法（设 $m = b-n+1$ 个网孔电流 $i_{m1}, \dots, i_{mm}$）

$$\begin{cases} R_{11}i_{m1}+R_{12}i_{m2}+\cdots+R_{1m}i_{mm}=u_{S11} \\ R_{21}i_{m1}+R_{22}i_{m2}+\cdots+R_{2m}i_{mm}=u_{S22} \\ \vdots \\ R_{m1}i_{m1}+R_{m2}i_{m2}+\cdots+R_{mm}i_{mm}=u_{Smm} \end{cases}$$

矩阵形式为 $R i_m = u_S$。
- $R_{kk} > 0$。
- 若所有网孔电流同取顺时针（或同取逆时针），则 $R_{jk} = R_{kj} < 0$。一般情况下，两网孔电流在公共支路上同向取 +，反向取 −。
- 无受控源时，$R_{jk} = R_{kj}$，系数矩阵对称。
- $u_{Skk}$ 为第 $k$ 个网孔中沿网孔电流方向的电压升代数和。电压源从 − 到 + 与绕行方向一致时取正。

3. 回路电流法：方程形式与网孔法相同，$l = b-n+1$ 个方程。互阻符号由回路电流在公共支路上的方向决定。

4. 节点电压法（取参考节点，设 $n-1$ 个节点电压 $u_{n1}, \dots, u_{n,n-1}$）

$$\begin{cases} G_{11}u_{n1}+G_{12}u_{n2}+\cdots+G_{1,n-1}u_{n,n-1}=i_{Sn11} \\ \vdots \\ G_{n-1,1}u_{n1}+\cdots+G_{n-1,n-1}u_{n,n-1}=i_{Sn,n-1,n-1} \end{cases}$$

矩阵形式为 $G u_n = i_{Sn}$。
- $G_{kk} > 0$，$G_{jk} = G_{kj} < 0$。
- $i_{Snkk}$ 是流入节点 $k$ 的电流源电流（含电压源串电阻等效的 $u_S/R$）的代数和，流入取正，流出取负。

5. 电源等效互换

$$i_S = \frac{u_S}{R}, \quad G = \frac{1}{R}$$

6. 弥尔曼定理（仅两个节点的电路）

$$u_{n1} = \frac{\sum G_k u_{Sk} + \sum i_{Sk}}{\sum G_k} = \frac{\sum \frac{u_{Sk}}{R_k} + \sum i_{Sk}}{\sum \frac{1}{R_k}}$$

分子中电压源取 $u_{Sk}$ 的"+"端朝向待求节点者为正，电流源流入该节点者为正。

##

1. 数错独立方程数：KCL 只有 $n-1$ 个，第 $n$ 个不独立。网孔数 $\neq$ 回路数的情形只出现在非平面电路中，非平面电路不能用网孔法。
2. 互阻、互导符号：网孔法中，方向相同取正，相反取负；节点法中互导一律为负。
3. 自导误含与电流源串联的电阻：与理想电流源串联的电阻不影响节点电压，$G_{kk}$、$G_{jk}$ 中均不计。
4. 电源符号：网孔法看"电压升"，节点法看"电流流入"，两者的符号约定不能混用。
5. 电流源与电压源互换：只对有伴电源有效。无伴电流源不能强行变成电压源。互换后，待求量所在支路不能被等效掉。
6. 无伴电流源处理遗漏补充方程：设其两端电压 $u$ 为新增未知量时，必须补 $i_{m1} - i_{m2} = \pm I_S$。
7. 受控源：先视为独立源列方程，再把控制量用网孔电流（节点电压）表示，补一个方程。此时矩阵一般不对称，不能套用 $R_{jk} = R_{kj}$。
8. 节点电压方程含无伴电压源：参考点未选在其一端时，漏设电压源电流或漏补 $u_{nj} - u_{nk} = U_S$。
9. 求支路量时忘记还原：求出的是网孔电流或节点电压，还需用 VCR 转换成支路电流、电压或功率。

##

题型 1：图论题（数独立方程、选树、找基本回路）
- 先数 $n$、$b$，再用 $n-1$、$b-n+1$ 计算。
- 选定树后，每增加一条连支就得到一个基本回路。回路方向取连支方向。

题型 2：支路电流法
- 步骤：标支路电流方向 → 对 $n-1$ 个节点列 KCL → 选 $b-n+1$ 个独立回路列 KVL，电阻上用 $Ri$ 表示 → 联立求解。
- 电路含电流源支路时，电流源支路电流已知，可少列方程，且 KVL 回路应避开它。

题型 3：网孔电流法
- 步骤：标网孔电流（通常全取顺时针）→ 观察写出 $R_{kk}$、$R_{jk}$、$u_{Skk}$ → 解方程 → 求支路量。
- 含电流源：
- 有伴：先转换为电压源串电阻。
- 无伴且在边缘支路：该网孔电流等于 $\pm I_S$，省去一个方程。
- 无伴且在公共支路：设电流源电压为 $u$ 并补方程；或选回路使电流源只属于一个回路（回路法）。

题型 4：回路电流法
- 适用于非平面电路，或需要灵活处理无伴电流源的电路。
- 技巧：令无伴电流源支路为连支，使其回路电流 $= \pm I_S$，减少未知量。受控源的控制量所在支路也可设为连支，使控制量直接成为回路电流。

题型 5：节点电压法（支路多、节点少的电路首选）
- 步骤：选参考节点（尽量选连接支路最多、或无伴电压源一端）→ 按规律写 $G_{kk}$、$G_{jk}$、$i_{Snkk}$ → 解方程 → 求支路电流 $i = G(u_n - \cdots)$。
- 含无伴电压源：
- 方法一：取其一端为参考点，另一端节点电压即为 $\pm U_S$，不必列该节点方程。
- 方法二：设电压源电流 $i$ 为未知量，补充 $u_{nj} - u_{nk} = U_S$。
- 含受控源：先写方程，再把控制量（如 $i_x$、$u_x$）用 $u_n$ 表示。

题型 6：两节点电路
- 直接套弥尔曼定理，几行即可求出节点电压。注意各电源方向与分子符号。

方法选择速记

| 条件 | 优先方法 |
| --- | --- |
| 网孔少、电压源多 | 网孔（回路）电流法 |
| 节点少、电流源多 | 节点电压法 |
| 非平面电路 | 回路电流法、节点电压法 |
| 仅两个节点 | 弥尔曼定理 |

检验技巧：求解后任取一个未参与列方程的节点验证 KCL，或取一个回路验证 KVL。也可用功率平衡检验：电源发出功率之和等于电阻吸收功率之和。
