# 第四章 电路定理　复习笔记

（编写：Arena · gpt-6.1-terra-low）

##

- 核心逻辑：电路定理是线性电路的一般性结论，利用这些定理可以简化电路分析，避免直接求解大量方程。
- 主要内容：叠加定理、替代定理、戴维宁定理、诺顿定理、最大功率传输定理、特勒根定理、互易定理。
- 适用范围：叠加定理、戴维宁定理、诺顿定理、互易定理适用于线性电路；特勒根定理适用于任何集中参数电路（线性或非线性）。
- 核心关系：戴维宁定理与诺顿定理是同一端口等效的两种形式；最大功率传输定理是戴维宁定理的直接应用。

##

1. 叠加定理
- 在线性电路中，任一支路的电压或电流，等于电路中每一个独立源单独作用时在该支路产生的电压或电流的代数和。
- 独立源单独作用时，其他独立源置零：独立电压源短路，独立电流源开路。
- 受控源不能单独作用，应保留在电路中，控制量随电路变化而变化。
- 功率不能用叠加定理计算，因为功率是电压与电流的乘积，不是线性量。

2. 替代定理
- 在电路中，若已知某支路的电压或电流，则该支路可以用一个电压源或电流源替代，替代后电路中其余支路的电压、电流不变。
- 替代定理适用于任何电路（线性或非线性），但替代后电路的拓扑结构不能改变。
- 替代定理的实质是：支路的电压、电流关系可以由外部等效源表示，而不改变其他支路的约束条件。

3. 戴维宁定理
- 任何线性一端口网络，对外电路而言，可以等效为一个电压源 $U_{oc}$ 与一个电阻 $R_{eq}$ 串联的电路。
- $U_{oc}$ 为一端口网络的开路电压，即端口开路时端口两端的电压。
- $R_{eq}$ 为一端口网络的等效电阻，即将一端口网络内部独立源置零后，从端口看进去的等效电阻。
- 戴维宁等效电路与原一端口网络具有相同的端口电压-电流关系。

4. 诺顿定理
- 任何线性一端口网络，对外电路而言，可以等效为一个电流源 $I_{sc}$ 与一个电阻 $R_{eq}$ 并联的电路。
- $I_{sc}$ 为一端口网络的短路电流，即端口短路时流过短路线的电流。
- $R_{eq}$ 与戴维宁定理中的等效电阻相同。
- 诺顿等效电路与戴维宁等效电路可以相互转换，转换关系为 $U_{oc} = I_{sc} R_{eq}$。

5. 等效电阻的求法
- 独立源置零法：将一端口网络内部的独立源置零（电压源短路、电流源开路），保留受控源，再求从端口看进去的等效电阻。
- 外加电源法：对一端口网络的端口加电压 $U$，求出流入端口的电流 $I$，或对端口注入电流 $I$，求出端口电压 $U$，则 $R_{eq} = \frac{U}{I}$。
- 短路电流法：若已知一端口网络的开路电压 $U_{oc}$ 和短路电流 $I_{sc}$，则 $R_{eq} = \frac{U_{oc}}{I_{sc}}$。
- 短路电流法要求 $I_{sc} \neq 0$，且开路、短路状态均能实现。

6. 最大功率传输定理
- 当负载电阻 $R_L$ 可变时，若负载与一端口网络的等效电阻 $R_{eq}$ 相等，则负载获得最大功率。
- 最大功率传输条件为 $R_L = R_{eq}$（$R_{eq} > 0$）。
- 最大功率传输时，负载功率为 $P_{L,max} = \frac{U_{oc}^2}{4 R_{eq}}$。

7. 特勒根定理
- 特勒根定理是功率守恒的一般形式，适用于任何集中参数电路。
- 特勒根定理 1：对于同一电路，所有支路电压与电流的乘积之和为零，即 $\sum_{k=1}^b u_k i_k = 0$（支路电压、电流取关联参考方向）。
- 特勒根定理 2：对于两个具有相同拓扑结构的电路，所有支路电压与电流的乘积之和也为零，即 $\sum_{k=1}^b u_k^{(1)} i_k^{(2)} = 0$。

8. 互易定理
- 互易定理适用于线性无源电路（不含受控源）。
- 互易定理表明，在线性无源电路中，激励与响应可以互换位置，响应值不变。
- 互易定理的典型形式为：在端口 1 施加电流 $I_1$，在端口 2 测得电压 $U_2$；在端口 2 施加电流 $I_2$，在端口 1 测得电压 $U_1$，则 $\frac{U_2}{I_1} = \frac{U_1}{I_2}$。

9. 对偶原理（编者补）
- 电路中某些元素、变量和关系互为对偶：电压 ↔ 电流、电阻 ↔ 电导、串联 ↔ 并联、网孔 ↔ 节点、KVL ↔ KCL。若某关系式成立，将其元素全部换为对偶元素，所得关系式也成立，可帮助记忆成对的公式。

##

1. 叠加定理

多个独立源单独作用时，电压、电流响应为：

$$u = \sum_{k=1}^n u_k, \quad i = \sum_{k=1}^n i_k$$

其中 $u_k$、$i_k$ 为第 $k$ 个独立源单独作用时产生的响应。

功率不能叠加：

$$P \neq \sum_{k=1}^n P_k$$

2. 戴维宁定理与诺顿定理

规定 $U$ 为端口电压，$I$ 为一端口向外部负载输出的电流，则端口关系为：

$$U = U_{oc} - R_{eq} I$$

当开路、短路状态均适用且 $I_{sc} \neq 0$ 时：

$$I_{sc} = \frac{U_{oc}}{R_{eq}}$$

外加电源法中，若测试电流 $I$ 取流入一端口的方向，则：

$$R_{eq} = \frac{U}{I}$$

3. 最大功率传输定理

戴维宁等效电路接负载 $R_L$ 时：

$$P_L = \frac{U_{oc}^2 R_L}{(R_{eq} + R_L)^2}$$

当 $R_{eq} > 0$、$R_L = R_{eq}$ 时：

$$P_{L,max} = \frac{U_{oc}^2}{4 R_{eq}}$$

4. 特勒根定理

同一电路中，所有支路采用关联参考方向时：

$$\sum_{k=1}^b u_k i_k = 0$$

对于拓扑相同的两个电路，可写成：

$$\sum_{k=1}^b u_k^{(1)} i_k^{(2)} = 0$$

5. 互易定理

互易电路中，在对应方向及边界条件下，可用转移电阻关系表示为：

$$\frac{U_2}{I_1} = \frac{U_1}{I_2}$$

其中两式分别指在端口 1 或端口 2 施加电流激励、在另一端口测量电压；测量端应满足相同的开路条件。

##

1. 叠加定理的适用范围：叠加定理仅适用于线性电路中的电压、电流，不能用于功率计算。功率是电压与电流的乘积，具有非线性，不能直接叠加。
2. 独立源置零的误操作：独立源置零时，电压源应短路，电流源应开路。受控源不能置零，应保留在电路中，并用电路变量表示控制量。
3. 戴维宁等效电路的端口关系：戴维宁等效电路的端口电压、电流关系为 $U = U_{oc} - R_{eq} I$，其中 $I$ 的方向为从一端口流向负载的方向。若 $I$ 的方向取相反，则公式中的符号应相应改变。
4. 等效电阻的求法选择
- 独立源置零法适用于无受控源的一端口网络。
- 外加电源法适用于含受控源的一端口网络。
- 短路电流法要求 $I_{sc} \neq 0$，且开路、短路状态均能实现。若 $I_{sc} = 0$，则短路电流法不适用。
5. 最大功率传输条件的适用范围：最大功率传输条件 $R_L = R_{eq}$ 仅适用于 $R_{eq} > 0$ 的情况。若 $R_{eq} < 0$（含受控源时可能出现），则最大功率传输条件不再适用。
6. 特勒根定理的适用范围：特勒根定理适用于任何集中参数电路，但要求支路电压、电流取关联参考方向，且电路的拓扑结构相同。
7. 互易定理的适用范围：互易定理仅适用于线性无源电路（不含受控源）。含受控源的电路一般不满足互易定理。
8. 替代定理的适用范围：替代定理适用于任何电路，但替代后电路的拓扑结构不能改变。替代定理的实质是支路的电压、电流关系可以由外部等效源表示，而不改变其他支路的约束条件。

##

1. 叠加定理的应用
- 将电路中的独立源逐个单独作用，其他独立源置零。
- 对每个独立源单独作用时的电路，求出待求支路的电压、电流。
- 将各独立源单独作用时的结果代数相加，注意符号。
- 功率不能用叠加定理计算，应先求出总电压、总电流，再计算功率。

2. 戴维宁定理的应用
- 求开路电压 $U_{oc}$：将负载断开，求端口两端的电压。
- 求等效电阻 $R_{eq}$：将独立源置零，求从端口看进去的等效电阻；或用外加电源法、短路电流法求解。
- 画出戴维宁等效电路，接上负载，求负载的电压、电流、功率。

3. 诺顿定理的应用
- 求短路电流 $I_{sc}$：将负载短路，求流过短路线的电流。
- 求等效电阻 $R_{eq}$：与戴维宁定理相同。
- 画出诺顿等效电路，接上负载，求负载的电压、电流、功率。

4. 最大功率传输问题
- 求一端口网络的戴维宁等效电路，得到 $U_{oc}$ 和 $R_{eq}$。
- 令负载电阻 $R_L = R_{eq}$，求最大功率 $P_{L,max} = \frac{U_{oc}^2}{4 R_{eq}}$。
- 若负载电阻可变范围有限，应在可变范围内求最大功率。

5. 特勒根定理的应用
- 对同一电路，列写所有支路电压与电流的乘积之和为零的方程。
- 对两个拓扑相同的电路，列写支路电压与电流的交叉乘积之和为零的方程。
- 特勒根定理可用于验证电路分析结果的正确性，或求解未知支路的电压、电流。

6. 互易定理的应用
- 确认电路为线性无源电路。
- 在端口 1 施加电流激励，在端口 2 测量电压；在端口 2 施加电流激励，在端口 1 测量电压。
- 利用 $\frac{U_2}{I_1} = \frac{U_1}{I_2}$ 的关系，求解未知量。
