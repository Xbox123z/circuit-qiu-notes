# 第二章 电阻电路的等效变换　复习笔记

（编写：Arena · gpt-6.1-terra-low）

##

- 主线：化简电路。目标是求解外电路中的电压、电流、功率，不必求出内部每一个支路细节。
- 核心依据：等效变换是"对外等效"，即等效前后外电路的电压、电流、功率均不变。
- 常用方法：串联与并联的等效电阻；Y-Δ 变换；电源模型等效变换；输入电阻的计算。
- 两种等效的差异：等效变换只保证外部特性不变，内部电压、电流、功率一般会改变。

##

1. 等效与对外等效
- 对一个端口来说，若两个电路或一部分电路具有相同的电压-电流关系（VCR），则它们在该端口上是等效的。
- 等效的判断只看端口电压、电流是否相同，不能因为内部支路相同就认定等效。
- 等效变换只在"对外等效"的前提下成立，等效前后内部电压、电流、功率一般不相等。

2. 电阻的串联
- 串联是指电流相同，端电压为各电阻电压之和。
- 串联电阻的等效电阻等于各电阻之和。
- 串联分压是按电阻值分配的。

3. 电阻的并联
- 并联是指电压相同，总电流为各支路电流之和。
- 并联电导的等效电导等于各支路电导之和。
- 并联分流是按电导值分配的，电阻越小，分得的电流越大。

4. Y 形与 Δ 形联结
- Y 形联结：三个电阻共接一个公共节点，另一端各自接外部节点。
- Δ 形联结：三个电阻首尾相接，形成闭合三角形。
- Y-Δ 变换是同一端口集合的两种连接方式之间的等效变换。
- 在三个电阻相等时，Y 形电阻等于 Δ 形电阻的 $\frac{1}{3}$，即 $\Delta = 3Y$。
- 变换后需满足同一端口上的电流、电压关系相同。

5. 电压源与电流源的串联和并联
- 理想电压源串联时，等效电压源的电压等于各电压源电压的代数和，符号由参考极性决定。
- 理想电压源并联时，各源电压必须相同，等效为同一电压源，但各源电流通常不能仅由外部条件唯一确定。理想电流源串联时，各源电流必须相同，等效为同一电流源，但各源电压通常不能仅由外部条件唯一确定。若这些约束不满足，则这种连接不允许。
- 理想电压源与电阻并联时，端电压由电压源决定，与并联电阻无关。
- 理想电流源与电阻串联时，支路电流由电流源决定，与串联电阻无关。
- 在等效变换中，电源与电阻的串联或并联关系不能随意混用。

6. 实际电源的两种模型
- 电压源模型：理想电压源与内阻串联。
- 电流源模型：理想电流源与内电阻并联。
- 两种模型在端口上是等效的，但内部结构不同。
- 在电压源模型中，输出电压随负载电流增大而减小；在电流源模型中，输出电流随端口电压变化而改变。

7. 输入电阻
- 输入电阻是从电路端口看进去的电阻，即端口电压与流入该端口电流之比。
- 输入电阻的计算对象是一个无源或含受控源的一端口电路。
- 计算输入电阻时，独立源一般置零：独立电压源短路、独立电流源开路。
- 含受控源时，输入电阻不能简单用电阻串并联法得到，应采用外加电源法：对端口加电压 $U$，求出流入端口的电流 $I$，或对端口注入电流 $I$，求出端口电压 $U$。
- 受控源在等效变换中一般不能独立置零，控制量仍由电路变量决定。

##

1. 串联

$$R_{eq} = R_1 + R_2 + \cdots + R_n$$

串联分压：

$$U_k = \frac{R_k}{R_1 + R_2 + \cdots + R_n} U$$

2. 并联

$$G_{eq} = G_1 + G_2 + \cdots + G_n$$

$$\frac{1}{R_{eq}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n}$$

两电阻并联：

$$R_{eq} = \frac{R_1 R_2}{R_1 + R_2}$$

并联分流：

$$I_k = \frac{G_k}{G_1 + G_2 + \cdots + G_n} I$$

两电阻并联分流：

$$I_1 = \frac{R_2}{R_1 + R_2} I, \quad I_2 = \frac{R_1}{R_1 + R_2} I$$

3. Y-Δ 变换

Δ 形转 Y 形：

$$R_1 = \frac{R_{12} R_{31}}{R_{12} + R_{23} + R_{31}}$$

$$R_2 = \frac{R_{23} R_{12}}{R_{12} + R_{23} + R_{31}}$$

$$R_3 = \frac{R_{31} R_{23}}{R_{12} + R_{23} + R_{31}}$$

Y 形转 Δ 形：

$$R_{12} = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_3}$$

$$R_{23} = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_1}$$

$$R_{31} = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_2}$$

4. 实际电源的两种模型

电压源模型：

$$U = U_S - R_0 I$$

电流源模型：

$$I = I_S - G_0 U$$

等效关系：

$$I_S = \frac{U_S}{R_0}, \quad G_0 = \frac{1}{R_0}$$

或等价地：

$$U_S = I_S R_0, \quad R_0 = \frac{1}{G_0}$$

5. 输入电阻

$$R_i = \frac{U}{I}$$

外加电源法：

$$R_i = \frac{U_S}{I_S}$$

当内含受控源时，$R_i$ 的结果可能与外加电压或外加电流的数值无关，但需按电路方程求解。

##

1. 内部量不相等：等效变换仅保证端口外电路的量不变。等效前后的内部电压、电流、功率一般不相同，不能用等效电路求原电路内部量。
2. 电源等效方向：电源等效变换时，参考方向必须一致。电压源的正极、电流源的参考方向一旦弄反，等效电路的电压、电流结果会全部反号。
3. Y-Δ 变换的变量对应：在 Y-Δ 变换中，电阻下标与节点对应关系是关键。Δ 形电阻 $R_{12}$、$R_{23}$、$R_{31}$ 与 Y 形电阻 $R_1$、$R_2$、$R_3$ 的对应关系不能随意交换。
4. 串并联判别：判断串并联时，应以电流是否相同、电压是否相同为标准，不能只凭图形画法判断。电桥电路中的电阻既不是串联也不是并联。
5. 含受控源的输入电阻：含受控源的一端口网络的输入电阻，不能直接用无源电阻串并联公式计算。应采用外加电源法，并保留受控源，列写电路方程求解。
6. 独立源置零范围：在求输入电阻时，独立源置零只适用于电路内部的独立源；若要计算的端口是外加电源的端口，外加电源本身不能置零。
7. 受控源置零错误：受控源的电压或电流由控制量决定，不能像独立源那样"置零"。在计算输入电阻时，受控源应保留在电路中，并用电路变量表示控制量。
8. 电源与电阻的关系：理想电压源与电阻并联时，并联电阻对端口电压没有影响；理想电流源与电阻串联时，串联电阻对支路电流没有影响。但这种"无影响"仅对外电路而言，电阻上的功率和电流、电压仍需按原电路计算。
9. 电源等效与待求支路：当需要求某一支路的电压、电流或功率时，该支路不能被等效变换掉。电源等效变换应在不改变待求支路的前提下进行，否则求出的结果是等效电路中的量，不是原电路中的量。

##

1. 电阻串并联的等效电阻
- 识别电流是否相同、电压是否相同。
- 串联时电阻相加，并联时电导相加；分压按电阻分配，分流按电导分配。
- 两电阻并联时，可直接用 $R_{eq} = \frac{R_1 R_2}{R_1 + R_2}$ 计算。

2. 电阻电路的化简
- 从最内层或最外层开始，逐步将串并联部分合并。
- 化简过程中保持端口不变，避免改变待求支路。
- 若化简后仍有桥形结构，可考虑 Y-Δ 变换或节点分析。

3. Y-Δ 变换
- 确认三端网络是 Y 形还是 Δ 形。
- 按公式代入，注意下标对应关系。
- 在三个电阻相等时，Y 形电阻等于 Δ 形电阻的 $\frac{1}{3}$，可快速计算。
- 变换后重新检查端口电压、电流关系是否一致。

4. 电源等效变换
- 确认电源与内阻的连接方式：电压源模型是电压源串联内阻，电流源模型是电流源并联内阻。
- 用 $I_S = \frac{U_S}{R_0}$ 或 $U_S = I_S R_0$ 进行等效变换，并保持内阻不变。
- 等效变换时，电源的参考方向必须与原电路一致。

5. 输入电阻
- 对无源一端口网络，直接用串并联公式计算。
- 对含受控源的一端口网络，采用外加电源法：加电压 $U$ 求电流 $I$，或注入电流 $I$ 求电压 $U$，再用 $R_i = \frac{U}{I}$ 计算。
- 计算时，独立源置零，保留受控源，并用电路变量表示控制量。

6. 等效电阻与短路处理
- 当端口短路时，等效电阻的计算应以短路后的电路为准。
- 若电路中存在电压源与电阻并联，短路后并联电阻可能被短路，需重新判断。
- 计算输入电阻时，若端口接有电源，应先将其等效为内阻，再按串并联或外加电源法计算。
