# 第五章 含有运算放大器的电阻电路　复习笔记

##

本章的主线是：运放模型 → 理想化条件 → 负反馈下的虚短、虚断 → 典型运算电路 → 节点电压法分析。

- 运算放大器是高增益差动放大器，可用受控源及输入、输出电阻建立电路模型。
- 理想运放在线性负反馈工作时，利用"虚短"和"虚断"可简化电路分析。
- 比例、加法、减法电路通过电阻网络实现信号的放大和代数运算。
- 将反馈或输入电阻换成电容，可形成积分、微分电路；这部分涉及动态电路，是对电阻电路分析方法的延伸。
- 对复杂含理想运放电路，节点电压法是通用方法：列节点方程，再加入理想运放约束。

##

### 1. 运算放大器的电路模型

运放有同相输入端 $+$、反相输入端 $-$ 和输出端。设两输入端对参考点的电压分别为 $u_+$、$u_-$，差模输入电压为 $u_d = u_+ - u_-$。

基本模型可视为一个电压控制电压源，其内部输出电压为 $u_o' = A u_d = A(u_+ - u_-)$，其中 $A$ 为开环电压增益。实际模型还包括输入电阻 $R_i$ 和输出电阻 $R_o$：$R_i$ 越大，输入电流越小；$R_o$ 越小，输出电压受负载的影响通常越小。

实际运放的输出电压受供电电源限制。若按线性模型算出的输出超出允许范围，运放进入饱和区，线性关系不再适用。

### 2. 理想运算放大器

理想运放通常取 $A \to \infty$，$R_i \to \infty$，$R_o = 0$。

由 $R_i \to \infty$，得到输入端电流为零：

$$i_+ = i_- = 0$$

这称为虚断：两输入端不吸收电流，但它们不是真正的断路节点，各自仍可连接其他支路。

当理想运放处于线性工作状态、输出有限时，由 $u_o = A(u_+ - u_-)$ 可得 $u_+ = u_-$。

这称为虚短：两端电压相等，但两端之间并无实际短路线，不能认为它们之间可以流过电流。

若同相端接地，则反相端电压也为零，称反相端为虚地。虚地与真实接地不同：虚地端没有直接接地的导线，分析时仍应对其列节点电流方程。

### 3. 负反馈与线性工作

负反馈是将输出变化经反馈网络送回输入端，产生抑制原输出变化的作用。典型反相比例电路中，输出经电阻反馈到反相端，构成负反馈。

判断顺序：先确认反馈及工作状态，再使用虚短。

虚断来自理想输入电阻无限大；虚短还要求运放处于线性工作状态。开环比较器、正反馈电路或已饱和的运放，一般不能直接使用 $u_+ = u_-$。

##

以下公式默认运放理想、处于线性工作状态，且电阻取值合法。

### 1. 反相比例运算电路

同相端接地，输入 $u_i$ 经 $R_1$ 接反相端，反馈电阻 $R_f$ 接于输出端与反相端之间：

$$u_o = -\frac{R_f}{R_1} u_i$$

负号表示输出与输入反相。由虚地、虚断可得：

$$\frac{u_i}{R_1} = -\frac{u_o}{R_f}$$

在上述连接方式下，输入源看到的输入电阻为 $R_1$。

### 2. 同相比例与电压跟随电路

输入加在同相端，反相端经 $R_1$ 接地、经 $R_f$ 接输出端：

$$u_o = \left(1 + \frac{R_f}{R_1}\right) u_i$$

输出与输入同相。由于理想运放输入电流为零，其输入电阻趋于无穷大。

若输出直接接反相端，构成电压跟随器：

$$u_o = u_i$$

它的电压增益为 $1$，常用于隔离前后级，减小负载效应。

### 3. 反相加法运算电路

各输入 $u_1, u_2, \dots, u_n$ 分别通过 $R_1, R_2, \dots, R_n$ 接反相端，同相端接地，反馈电阻为 $R_f$：

$$u_o = -R_f\left(\frac{u_1}{R_1} + \frac{u_2}{R_2} + \cdots + \frac{u_n}{R_n}\right)$$

若 $R_1 = R_2 = \cdots = R_n = R$，则：

$$u_o = -\frac{R_f}{R}(u_1 + u_2 + \cdots + u_n)$$

各输入项的权重由对应输入电阻决定。

### 4. 减法运算电路

设 $u_1$ 经 $R_1$ 接反相端，输出经 $R_2$ 反馈到反相端；$u_2$ 经 $R_3$ 接同相端，同相端经 $R_4$ 接地。由于同相端不吸收电流：

$$u_+ = \frac{R_4}{R_3 + R_4} u_2$$

利用 $u_- = u_+$ 并对反相端列方程，得：

$$u_o = \left(1 + \frac{R_2}{R_1}\right)\frac{R_4}{R_3 + R_4} u_2 - \frac{R_2}{R_1} u_1$$

当电阻满足比例匹配条件 $\frac{R_2}{R_1} = \frac{R_4}{R_3}$ 时，化为：

$$u_o = \frac{R_2}{R_1}(u_2 - u_1)$$

应记清输入端位置：此连接下 $u_2$ 对应正项，$u_1$ 对应负项。

### 5. 积分与微分电路要点

反相积分电路：输入支路为电阻 $R$，反馈支路为电容 $C$，同相端接地。由虚地和电容电流关系：

$$\frac{du_o}{dt} = -\frac{1}{RC} u_i$$

因此：

$$u_o(t) = u_o(t_0) - \frac{1}{RC}\int_{t_0}^{t} u_i(\tau) d\tau$$

积分结果必须保留初始输出 $u_o(t_0)$；实际电路还要考虑失调和输出饱和。

反相微分电路：输入支路为电容 $C$，反馈支路为电阻 $R$：

$$u_o = -RC\frac{du_i}{dt}$$

实际微分电路对高频噪声敏感，通常需采用限频措施。上述动态关系仍以理想运放线性工作为前提。

##

1. 把虚短当成真实短路。$u_+ = u_-$ 只表示电压相等；两个输入端应分别处理，不能添加一条能任意导电的短路线。
2. 把虚地当成真实地。虚地电压虽为零，但不能忽略与该节点相连的输入、反馈支路电流。
3. 任何情况下都套用虚短。运放饱和、开环或处于正反馈状态时，不能仅凭"理想运放"就令 $u_+ = u_-$。
4. 误认为输入电流为零，相关电阻中电流也为零。流入运放端子的电流为零，但连接该节点的电阻支路仍可有电流。
5. 公式脱离接线条件。比例、加法和减法公式中的电阻及输入端位置不可随意互换；不匹配时应重新列方程。
6. 忽略输出限制和初始条件。实际运放输出受电源限制；积分电路的输出还与初始电压有关。

##

### 1. 已知输入求输出

先识别反相、同相、加法或减法结构，再核对电阻连接和参考极性；符合标准结构时直接套公式，否则列节点方程。若给定电源电压，还要检查所得输出是否处于线性范围。

### 2. 根据目标运算关系设计电阻

将目标式与标准式逐项比较。例如反相加法中，第 $k$ 路输入的系数为 $-\frac{R_f}{R_k}$。先由系数确定电阻比，再选取合适的电阻值。减法电路不仅要确定增益，还要满足电阻比例匹配。

### 3. 含理想运放电路的节点电压法

对于非标准电路，按以下步骤分析：

1. 选参考节点，标出未知节点电压，包括 $u_+$、$u_-$ 和 $u_o$。
2. 判断是否可按线性负反馈处理；若可以，写出 $u_+ = u_-$ 及 $i_+ = i_- = 0$。
3. 对输入端及其他必要节点列 KCL。电阻支路电流统一写成"本节点电压减相邻节点电压，再除以电阻"。
4. 将输出电压作为未知量参与联立；若在输出节点列 KCL，必要时将运放输出电流另设为未知量，不能误设为零。
5. 求解后检查符号、量纲及实际输出范围；多级电路还应考虑前级是否受到后级负载影响。

检查原则：理想运放输入端不吸收电流，但输出端可以提供或吸收电流；线性分析得到的结果必须与所假设的工作状态相容。
