# 第一章 电路模型和电路定律　复习笔记

（编写：Arena · claude-sonnet-5-5-high）

##

- 核心逻辑：实际电路 → 电路模型 → 电路定律 → 求解。
- 两条主线：
1. 元件约束：电阻、电压源、电流源、受控源（由元件性质决定）
2. 拓扑约束：KCL、KVL（由连接方式决定）
- 分析流程：画模型 → 标参考方向 → 用 KCL、KVL 与 VCR 联立 → 求电流、电压、功率、电位。

##

- 电路模型：用理想元件（电阻、电源等）及连接方式抽象实际电路；忽略次要因素，抓住主要电磁性能。同一实际电路在不同条件下可采用不同模型。
- 电流：单位时间内通过导体横截面的电荷量，方向为正电荷运动方向。公式 $i = \frac{dq}{dt}$；在直流（恒定）情况下 $I = \frac{Q}{t}$。
- 电压：单位正电荷从一点移到另一点时电场力做的功（电位能的变化），$u = \frac{dw}{dq}$，$U = \frac{W}{Q}$（直流）。
- 电位：某点相对于参考点的电压，记 $\varphi$，参考点电位为零。两点间电压 $U_{ab} = \varphi_a - \varphi_b$。
- 参考方向：人为假定的电流、电压正方向。实际方向与参考方向一致时值为正，相反时为负。原则：参考方向一经选定，整个分析过程中不再改变。
- 关联参考方向：电流参考方向与电压参考方向一致（电流从电压"+"端流入，从"-"端流出）。非关联参考方向：电流从电压"-"端流入（或从"+"端流出）。
- 电功率：元件吸收（消耗）功率 $p = ui$（关联参考方向下）；元件发出功率 $p = -ui$（关联参考方向下，非关联时正负号互换）。功率正负判断：$p > 0$ 表示吸收功率，$p < 0$ 表示发出功率。
- 电阻元件：只消耗电能，不储存能量，电压与电流满足欧姆定律 $u = Ri$（关联参考方向下）。电阻 $R$ 单位欧姆（$\Omega$），电导 $G = \frac{1}{R}$ 单位西门子（S），$i = Gu$。
- 电压源：端电压恒定，与流过它的电流无关。理想电压源内阻为零，端电压 $u = U_S$（$U_S$ 为定值）。其电流由外电路决定。
- 电流源：输出电流恒定，与其两端电压无关。理想电流源内阻为无穷大，输出电流 $i = I_S$（$I_S$ 为定值）。其端电压由外电路决定。
- 受控电源：电压或电流受电路中另一支路电压或电流控制的电源。受控电压源：VCVS（电压控制电压源）、CCVS（电流控制电压源）；受控电流源：VCCS（电压控制电流源）、CCCS（电流控制电流源）。
- 基尔霍夫电流定律（KCL）：在任一时刻，流出（或流入）任一节点的电流代数和为零：$\sum i = 0$。即"流入 = 流出"，或 $\sum i_{\text{入}} = \sum i_{\text{出}}$。
- 基尔霍夫电压定律（KVL）：在任一时刻，沿任一回路绕行一周，各支路电压代数和为零：$\sum u = 0$。即沿绕行方向"电压降之和 = 电压升之和"，或 $\sum u_{\text{降}} = \sum u_{\text{升}}$。

##

1. 电流、电压定义
- $i = \frac{dq}{dt}$，直流：$I = \frac{Q}{t}$
- $u = \frac{dw}{dq}$，直流：$U = \frac{W}{Q}$
2. 电位与电压
- $U_{ab} = \varphi_a - \varphi_b$，$\varphi_a = U_{a0}$（0 为参考点）
3. 电阻元件
- $u = Ri$，$i = Gu$，$G = \frac{1}{R}$，$p = ui = i^2 R = \frac{u^2}{R}$
4. 电功率（关联参考方向下）
- 吸收功率：$p = ui$
- 发出功率：$p = -ui$
- 功率平衡（整个电路）：$\sum p_{\text{吸收}} = \sum p_{\text{发出}}$，或 $\sum p = 0$（吸收取正、发出取负）
- 能量（编者补，对应 §1-3"电功率和能量"）：元件从 $t_0$ 到 $t$ 吸收的能量 $w = \int_{t_0}^{t} p \, d\xi$；$p > 0$ 时能量增加（吸收），$p < 0$ 时能量减少（发出）
5. KCL、KVL
- KCL：$\sum i = 0$
- KVL：$\sum u = 0$
6. 受控源
- VCVS：$u_2 = \mu u_1$
- CCVS：$u_2 = r i_1$
- VCCS：$i_2 = g u_1$
- CCCS：$i_2 = \beta i_1$
- 其中 $\mu$ 无量纲，$r$ 单位 $\Omega$，$g$ 单位 S，$\beta$ 无量纲。

##

1. 参考方向未标或中途改变：必须先标参考方向再计算；数值正负只表示与参考方向的关系，不是实际方向错误。
2. 关联与非关联混淆：用 $p = ui$ 判断吸收/发出时，必须先确认是否为关联参考方向；非关联时吸收功率为 $p = -ui$。
3. 电压源、电流源性质颠倒：电压源端电压恒定，电流由外电路决定；电流源电流恒定，端电压由外电路决定。理想电压源不能短路，理想电流源不能开路。
4. 电位计算错误：电位与参考点选取有关，电压与参考点选取无关；求某点电位时，必须沿一条路径从该点走到参考点，电压降取正、电压升取负（或按绕行方向累加）。
5. KCL、KVL 符号错误：列 KCL 时流入取正、流出取负（或反之，全电路统一）；列 KVL 时绕行方向上电压降取正、电压升取负（或反之，全电路统一）。
6. 受控源当作独立源：受控源的控制量是电路中的变量，不能随意设定；含受控源的电路，功率平衡仍成立，但受控源可能吸收也可能发出功率。
7. 单位与数量级错误：$R$ 与 $G$ 互为倒数，勿将电导当电阻代入；计算功率时注意 mA、kΩ 等单位换算。

##

题型 1：判断电流、电压实际方向
- 先看参考方向，再看计算结果正负：正值表示实际方向与参考方向一致，负值表示相反。

题型 2：求电功率，判断吸收/发出
- 步骤：确认参考方向是否关联 → 用 $p = ui$（关联）或 $p = -ui$（非关联）计算吸收功率 → $p > 0$ 吸收，$p < 0$ 发出。
- 技巧：全电路功率平衡可用于验算：$\sum p = 0$。

题型 3：求电位
- 步骤：选定参考点 → 从待求点沿任意路径走到参考点 → 路径上电压降取正、电压升取负，累加得到电位。
- 技巧：不同路径结果应相同，可换路径验算。

题型 4：含受控源的电路分析
- 步骤：把受控源当作独立源处理 → 列 KCL、KVL 方程 → 将控制量用电路变量表示，代入方程联立求解。
- 注意：控制量所在支路不能随意等效掉。

题型 5：KCL、KVL 综合应用
- 步骤：标出所有支路电流、电压参考方向 → 对节点列 KCL，对回路列 KVL → 结合元件 VCR（如 $u = Ri$）联立求解未知量。
- 技巧：先数清未知量个数，再列相同数量的独立方程，避免多列或少列。

解题总流程：
标参考方向 → 标电压、电流 → 列 KCL、KVL → 代入 VCR → 求解并判断功率与实际方向。
